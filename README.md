# Student Record Management System

A C++ based Student Record Management System demonstrating object-oriented programming concepts.

## Features

- Add Student
- Display All Students
- Search Student
- Update Student
- Delete Student
- Exit the application
- Store student records using file handling
- Calculate and display student grades

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Git
- GitHub
